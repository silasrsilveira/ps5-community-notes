PS5 Community Notes
Registro comunitário de informações públicas e verificáveis sobre compatibilidade.

Campos
modelo: modelo indicado pela fonte.
versao_sistema: versão do sistema indicada pela fonte.
tema: assunto da observação.
resultado: o que a fonte afirma ou o teste observou.
fonte: URL ou referência verificável.
data: data em que a informação foi conferida, no formato AAAA-MM-DD.
confianca: confirmado, relatado ou nao_verificado.
Critérios
Inclua uma fonte para cada registro.
Diferencie resultados confirmados de relatos não reproduzidos.
Não registre conjecturas como fatos.
Atualize a data ao revalidar uma informação.
