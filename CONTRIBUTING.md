# Como contribuir

## Antes de adicionar uma linha

- Registre uma observação por linha.
- Inclua uma fonte verificável para cada observação.
- Prefira fontes primárias, como documentação oficial.
- Descreva apenas o que a fonte ou o teste realmente confirma.
- Não conclua que uma versão é compatível com determinado recurso se a fonte não disser isso.
- Não inclua números de série, identificadores de conta ou outros dados pessoais.

## Nível de confiança

- `confirmado`: a afirmação está explícita numa fonte primária ou foi reproduzida e documentada.
- `relatado`: há uma fonte identificável, mas o resultado ainda não foi reproduzido independentemente.
- `nao_verificado`: a fonte ou o resultado ainda não pôde ser confirmado.

## Formato do CSV

- Mantenha o cabeçalho existente e use uma linha por observação.
- Use datas no formato `AAAA-MM-DD`.
- Use exatamente `confirmado`, `relatado` ou `nao_verificado` no campo de confiança.
- Cole a URL como texto simples, sem crases ou formatação Markdown.
- Se um campo contiver vírgula, coloque o campo entre aspas duplas.
- Antes de enviar uma alteração, confira se cada linha tem sete campos.
